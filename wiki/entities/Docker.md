# Docker

## Summary

Docker packages applications and dependencies into containers so an AI-agent application can run consistently across developer machines, servers, and cloud environments. [[2026-07-07-building-ai-agents-with-llms-rag-knowledge-graphs]] treats Docker as a step from [[Streamlit]] prototype toward reproducible production deployment.

## Connections

- [[Kubernetes]] - orchestrates containers after packaging.
- [[Agent Deployment]] - containerization makes agent apps easier to ship and operate.
- [[LLMOps]] - deployment and runtime management discipline for LLM systems.
