# OpenModelica

Open-source modeling and simulation environment for acausal (equation-based) modeling of physical systems. Used in digital twin applications for continuous-system simulation.

## Key Features

- **Acausal modeling** — define equations without specifying signal flow direction
- **Modelica language** — standardized, object-oriented modeling language
- **Physical domains** — electrical, mechanical, thermal, fluid, and multi-domain systems
- **Simulation** — ODE solvers with variable step size and event handling
- **FMI export** — generate Functional Mock-up Units for co-simulation

## Use Cases

- HVAC system simulation for building digital twins
- Manufacturing process optimization
- Energy system modeling
- Automotive system simulation
