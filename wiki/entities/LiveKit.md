LiveKit is an open-source real-time communication infrastructure built on WebRTC for voice and video applications. It provides the transport layer for voice agent deployments, handling audio/video streams, participant management, and scalable media routing.

## Key Features
- Open-source WebRTC-based infrastructure for low-latency audio and video
- Scalable SFU (Selective Forwarding Unit) architecture for multi-party sessions
- Client SDKs for web, mobile, and server environments
- Recording and transcription hooks for voice agent integration
- Edge-deployed regions for global low-latency connectivity
