# Streamlit

## Summary

Streamlit is a Python web-application framework used to turn data and AI workflows into interactive apps without a separate frontend stack. [[2026-07-07-building-ai-agents-with-llms-rag-knowledge-graphs]] uses it as the prototyping layer for AI-agent applications before production hardening.

- [[LLMOps]] - production systems need monitoring, scaling, and governance beyond a prototype UI.
