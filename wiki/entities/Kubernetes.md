# Kubernetes

## Summary

Kubernetes is a container-orchestration platform for deploying, scaling, networking, and managing containerized applications. [[2026-07-07-building-ai-agents-with-llms-rag-knowledge-graphs]] discusses it as the next operational layer after packaging agent applications with [[Docker]].

## Connections

- [[Docker]] - packaging substrate for containerized services.
- [[Agent Deployment]] - production scaling layer for agent applications.
- [[LLMSecOps]] - Kubernetes manifests and container permissions can introduce security misconfiguration risk.
