# Toolformer

## Summary

Toolformer is an LLM tool-use approach in which the model learns, largely through self-supervised annotation, when to call external APIs such as calculators, search engines, or calendars. [[2026-07-07-building-ai-agents-with-llms-rag-knowledge-graphs]] presents it as an early pattern for making tool use a general model skill rather than a task-specific wrapper.

## Connections

- [[Tool Use]] - core capability Toolformer trains into an LLM.
- [[OpenAI Function Calling]] - modern product-facing interface for structured tool invocation.
- [[Agentic Systems]] - tool invocation is part of the action layer.
