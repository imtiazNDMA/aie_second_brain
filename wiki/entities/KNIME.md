# KNIME

Data analytics platform providing visual workflow builder for data integration, ETL, and analytics pipelines. Connects to LLM flows via APIs, enabling structured data processing combined with unstructured text analysis.

## Key Features

- **Visual workflow** — drag-and-drop data pipeline construction
- **ETL** — extract, transform, load for structured and unstructured data
- **LLM integration** — connect to LangChain/Langflow flows via APIs
- **1000+ nodes** — pre-built connectors and processors
- **Free and enterprise** — open-source core with commercial extensions

## Use Cases

- CRM data pipeline → LLM analysis → structured output
- Document processing with OCR → NER → knowledge graph
- Batch inference workflows with quality gates
- Data preparation for LLM fine-tuning
