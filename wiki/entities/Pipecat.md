Pipecat is an open-source framework for building real-time multimodal AI agents. It provides conversation flow management, integrated TTS/STT pipelines, and transport abstraction to simplify the development of voice-enabled AI applications.

## Key Features
- Modular pipeline architecture for composing STT, LLM, and TTS components
- Built-in conversation flow management with interrupt handling and turn-taking
- Transport abstraction supporting LiveKit, WebRTC, and other real-time transports
- Frame-based message passing for low-latency audio and text processing
- Extensible processor system for custom voice agent behaviors
