# ADR 0003: Original Gamified UI and Brand Safety

Status: Amended by ADR 0007

Date: 2026-07-07

## Context

The platform should feel as habit-forming and polished as a modern consumer learning app. The project uses Duolingo-style language internally to describe learning mechanics, but must not copy Duolingo's protected brand, mascot, art, exact colors, copy, screens, sounds, or proprietary UI patterns.

## Decision

Create an original AI Engineering learning identity. Use path-based progression, XP, streaks, mastery gates, short lessons, review queues, and celebratory feedback as general learning mechanics, but express them through original product naming, visual language, copy, animation, iconography, node shapes, and AI Engineering-themed environments.

## Consequences

- The UI can be playful without creating brand or legal risk.
- Design work must be reviewed against originality constraints, not only visual polish.
- The app should avoid a dry LMS/admin-dashboard feel.
- Brand safety becomes a release criterion for MVP assets and screens.

## Quality Gates

- No Duolingo mascot, protected characters, artwork, animation files, copy, sounds, exact color palette, or exact screen layouts are used.
- The first viewport clearly signals the original product identity and active learning path.
- Lesson nodes, badges, illustrations, and completion states use original AI Engineering motifs.
- Gamification rewards mastery and project proof, not only daily activity.
- UI copy avoids Duolingo-adjacent phrasing in shipped surfaces.
